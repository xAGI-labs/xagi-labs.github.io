# Dataset readiness discussion checklist

- [ ] Source identity and authorized rights holder identified
- [ ] Collection purpose and permission evidence documented
- [ ] Third-party rights, privacy and confidentiality restrictions identified
- [ ] Coverage, formats, metadata and quality limitations described
- [ ] Proposed model uses and restrictions specified
- [ ] Representative pilot and acceptance checks proposed
- [ ] Secure sample review agreed before transfer

This is a preparation tool, not legal clearance, certification or valuation. Discuss a source at https://xagi.in/data-partnerships/.

## Preparing a voice evaluation pilot

- [ ] Model task, observed failure and evaluation decision defined
- [ ] Languages, dialects, code-switching and speaker groups specified
- [ ] Hard acoustic, device and conversation conditions described
- [ ] Held-out sample, speaker separation and duplicate checks planned
- [ ] Source and proposed evaluation permissions available for review
- [ ] Scoring rubric, reviewer guidance and acceptance criteria documented

Use the interactive tool for a tailored preparation plan: https://xagi.in/dataset-readiness-checklist/.
Review pilot deliverables: https://xagi.in/voice-evaluation-pilot/.
Sample size, access, price and timing require scoping; completing this checklist does not guarantee availability or model improvement.
