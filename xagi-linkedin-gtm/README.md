# AI data sourcing GTM toolkit
Sanitized task documentation and blank pipeline templates. Actual contact research, profile audit, outreach drafts, opportunities and browser evidence are local-only and excluded from this public repository. This backup does not cover the private local pipeline.

Use source evidence, explicit unknown values and conservative scores. Keep a confirmed buyer requirement separate from model/product fit. Verify dataset provenance, participant consent and training/licensing authority before collection or transfer. Apply outbound approval controls before any communication.

See SCORING_METHODOLOGY.md. Banner is a review draft; BANNER_SPEC.md states required dimensions and export limitation.
